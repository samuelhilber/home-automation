# ADR-014: Home Assistant starts the Spotify playlist directly

- Status: Accepted
- Date: 2026-11-03

## Context

Replaces ADR-013, which Samuel rejected on 3 Nov 2026.

## Decision

Home Assistant starts the Spotify playlist directly (Spotify integration) and plays it on the chosen Sonos zone.

## Consequences

Needs Spotify Premium, which Samuel has.
