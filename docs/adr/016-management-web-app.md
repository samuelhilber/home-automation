# ADR-016: Calendars and the per-event preview switch are managed in one management web app

- Status: Accepted
- Date: 2026-11-03

## Context

Samuel's choice on 3 Nov 2026. Keeps work and school calendars untouched and puts all settings in one place.

## Decision

Calendars and the per-event preview switch are managed in one management web app, opened on the phone or computer. Nothing is marked inside the calendar apps.

## Consequences

None recorded yet.
