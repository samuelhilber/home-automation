# ADR-010: All picked calendars merge into one calendar view

- Status: Accepted
- Date: 2026-11-03

## Context

Samuel's answer on 3 Nov 2026. Some calendars are imported and may duplicate events.

## Decision

All picked calendars merge into one calendar view, chosen on a settings page. Duplicates are handled in 2.0.

## Consequences

Duplicate events can show up in 1.0.
