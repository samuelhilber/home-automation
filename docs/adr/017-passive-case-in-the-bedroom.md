# ADR-017: The Pi sits in the bedroom in a passive, fanless case

- Status: Accepted
- Date: 2026-11-03

## Context

Samuel's choice on 3 Nov 2026: silence matters more than speed. Raspberry Pi calls cooling optional for normal use.

## Decision

The Pi sits in the bedroom in a passive, fanless case. Backups run automatically at night.

## Consequences

Heavy jobs may slow down a little, which is harmless at night.
