# ADR-018: Updates are never installed automatically

- Status: Accepted
- Date: 2026-11-03

## Context

Samuel's choice on 3 Nov 2026. Updates have broken the Sonos and TV integrations before, so release notes are read first. Home Assistant lists each pending update with its version and release notes and offers an install action the page can call.

## Decision

A pop-up in the management web app announces updates and Samuel confirms each one by hand.

## Consequences

See ADR-019 for when a confirmed update may run.
