# ADR-013: The Spotify playlist is saved as a Sonos favourite and Home Assistant starts it

- Status: Rejected
- Date: 2026-11-03

## Context

Starting a Sonos favourite is simpler and more reliable than controlling Spotify directly.

## Decision

Proposed: save the playlist as a Sonos favourite and have Home Assistant start that favourite. Samuel rejected it on 3 Nov 2026.

## Consequences

Replaced by ADR-014.
